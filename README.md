# Atmos X

Find the hottest blocks around you from NASA satellite data, get a concrete cooling plan, plant and track trees that are proven alive, team up with neighbours, spend verified points in a store, and (for farmers) get crop and weather alerts, in 10 languages. Built for the NASA Space Apps Challenge 2026; Dhaka is the home story and the app works worldwide.

**Live:** <https://atmosx.baksho.app>

## What it does

- **Scan your area.** The app rates every H3 hexagon (about 15,000 m²) within 200 m, 500 m or 1 km of you with a Heat Score from 0 to 100. The score comes from Landsat surface temperature, sharpened with ECOSTRESS where a pass exists, and the hottest hexagons are grouped into zones.
- **See why it is hot.** Each zone shows its drivers (sealed surfaces, missing green cover, water, dark surfaces) and how many °C each adds, fitted on the satellite data.
- **Heat now.** Shows air temperature, feels-like, today's high against the normal for the date (NASA POWER) and a 5-day forecast (NASA GEOS-FP). In Bangladesh it adds the BMD heat-wave and cold-wave levels.
- **Plan.** Set a cooling goal for a zone and get a plan with planting spots, species, costs and an "act vs don't act" projection to 2040 (NEX-GDDP-CMIP6).
- **Act and track.** Log an action with a GPS-sealed photo and check each tree every 15 days. Points stay pending until a tree passes its 90-day check-in, then they become spendable. Badges and leaderboards are built on the same records.
- **Community and store.** Teams, organizations, a feed, planting drives, a points store with partner products, and a company page for funding verified trees.
- **Air quality.** PM2.5 and AQI from NASA GEOS-CF, the Copernicus (CAMS) model and OpenAQ stations, plus your own sensor.
- **Farmer mode.** Crop alerts for heat, cold, heavy rain, drought and lightning, by crop and growth stage, using IMERG rain, SMAP soil moisture and the LIS/OTD lightning record.
- **Ask Atmos.** Answers questions from the app's own data, with source chips, on every screen. There is no language model: answers are templates filled with real numbers.

Every number in the app shows its source and whether it is an observation, a model value, a forecast or an estimate. Nothing is generated by AI.

## NASA data and APIs used

NASA's data and APIs are publicly available, and no special NASA Space Apps API key is needed. Atmos X uses no `api.nasa.gov` key either:

- NASA POWER, GIBS, GEOS (NCCS) and the ORNL MODIS service need no key.
- Landsat, HLS and MODIS are read from public mirrors on Microsoft Planetary Computer.
- A free [NASA Earthdata Login](https://urs.earthdata.nasa.gov) is needed only for the Earthdata files marked below. Without one, those features fall back and say so.

| NASA dataset or API | Provider | Access | Used for |
| --- | --- | --- | --- |
| [Landsat 8/9 Collection 2 Level-2](https://planetarycomputer.microsoft.com/dataset/landsat-c2-l2) surface temperature | NASA/USGS | Planetary Computer STAC, no key | Hexagon surface temperature, reflectance, albedo |

| [MODIS Land Surface Temperature MOD11/MYD11 v6.1](https://planetarycomputer.microsoft.com/dataset/modis-11A2-061) | NASA LP DAAC | Planetary Computer STAC, no key | Night heat, 20-year history, 1 km fallback |
| [ECOSTRESS ECO_L2T_LSTE v002](https://lpdaac.usgs.gov/products/eco_l2t_lstev002/) | NASA JPL, LP DAAC | Earthdata CMR-STAC, Earthdata Login | Sharpening the daytime heat pattern; night heat |

How this maps to NASA's platforms:

- [NASA Earthdata](https://earthdata.nasa.gov): Earthdata Login and the CMR catalogue. Earthdata archives distribute HLS, MODIS and ECOSTRESS (LP DAAC), IMERG (GES DISC), SMAP (NSIDC), LIS/OTD (GHRC), the MODIS web service (ORNL DAAC) and GPW (SEDAC). GIBS is Earthdata's imagery service. Landsat comes from USGS.
- [NASA JPL](https://www.jpl.nasa.gov): ECOSTRESS is a JPL instrument on the International Space Station.
- [NASA API portal](https://api.nasa.gov) and [NASA Open Data](https://data.nasa.gov): not needed, because none of the APIs above use an `api.nasa.gov` key.

Other open data used: [ESA WorldCover](https://esa-worldcover.org) 10 m land cover (2021), [Open-Meteo](https://open-meteo.com) current weather and the CAMS air-quality model, [OpenAQ](https://openaq.org) PM2.5 stations, [OpenStreetMap](https://www.openstreetmap.org/copyright) (Nominatim place names, Overpass buildings, roads and nurseries) with [OpenFreeMap](https://openfreemap.org) map tiles, [DB-IP](https://db-ip.com) City Lite, and the Bangladesh Meteorological Department heat, cold and rain thresholds.

The live status of every source is in [docs/v1/source-check.md](docs/v1/source-check.md) (`make verify-sources`), at `/api/v1/sources`, and on the app's About page.

## Monorepo

| Path | What |
| --- | --- |
| `apps/web` | Next.js 16 landing page, web app and installable PWA. Talks only to the API through `/api/v1` rewrites. |
| `apps/api` | FastAPI + Postgres/PostGIS API and the job worker: heat pipeline, NASA providers, accounts, trees, points, community, store, payments. |

Atmos X ships only as a web app and installable PWA; there is no native app.

## Run it locally

Needs Docker, Python 3.12+ with [uv](https://docs.astral.sh/uv/), and Node 22.

```bash
cp .env.example .env     # the core heat loop works with no third-party keys
make env                 # copies only the web variables into apps/web/.env.local
cd apps/web && npm ci && cd ../..
make dev                 # Postgres (5433) + migrations + reference data, then API (8000), worker and web (3000)
```

Open <http://localhost:3000> and choose "Try the Dhaka demo", or open `/app?demo=1`. The demo story is invented and never mixes with real data.

Other targets: `make test`, `make lint`, `make e2e` (Playwright, Chromium only), `make gen-client` (OpenAPI → typed web client), `make verify-sources` (one real request per data source), `make precompute` (Dhaka heat now). Create the first admin with `cd apps/api && uv run python -m app.scripts.make_admin you@example.org`.

## Deploy

`docker-compose.prod.yml` runs Postgres/PostGIS, the API, the worker and the web server; `deploy/` holds the nginx site. See [DEV-CHECKLIST.md](DEV-CHECKLIST.md) §5 before going live.
