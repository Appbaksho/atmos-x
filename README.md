<h3 align="center">By Team Psycodes</h3>

Atmos X finds the hottest blocks around you from NASA satellite data, gives you a concrete cooling plan, and helps you plant and track trees that are proven alive. You can team up with neighbours and spend verified points in a store, and farmers get crop and weather alerts. It works in 10 languages. Built for the NASA Space Apps Challenge 2026: Dhaka is the home story, and the app works worldwide.

**Visit Atmos X:** <https://atmosx.baksho.app>

## What it does

- **Scan your area.** The app gives every H3 hexagon (about 15,000 m²) within 200 m, 500 m or 1 km of you a Heat Score from 0 to 100. The score comes from Landsat surface temperature, sharpened with ECOSTRESS where a pass exists, and the hottest hexagons are grouped into zones.
- **See why it is hot.** Each zone lists its drivers (sealed surfaces, missing green cover, water, dark surfaces) and how many °C each one adds. These figures are fitted on the satellite data.
- **Heat now.** Shows the air temperature, feels-like temperature, today's high against the normal for the date, and a 5-day forecast. In Bangladesh it adds the BMD heat-wave and cold-wave levels.
- **Plan.** Set a cooling goal for a zone. The plan lists planting spots, species and costs, and projects the zone to 2040 both with and without the plan.
- **Act and track.** Log an action with a GPS-sealed photo and check each tree every 15 days. Points stay pending until a tree passes its 90-day check-in, then they become spendable. Badges and leaderboards are built on the same records.
- **Community and store.** Teams, organizations, a feed, planting drives, a points store with partner products, and a company page for funding verified trees.
- **Air quality.** PM2.5 and AQI from a NASA forecast, the Copernicus model and measuring stations, plus your own sensor.
- **Farmer mode.** Crop alerts for heat, cold, heavy rain, drought and lightning, by crop and growth stage.
- **Ask Atmos.** Answers questions from the app's own data, with source chips, on every screen. Answers are templates filled with real numbers; no language model writes them.

Every number in the app shows its source and whether it is an observation, a model value, a forecast or an estimate. Nothing is generated by AI.

## Monorepo

| Path | What |
| --- | --- |
| `apps/web` | Next.js 16 landing page, web app and installable PWA. Talks only to the API through `/api/v1` rewrites. |
| `apps/api` | FastAPI + Postgres/PostGIS API and the job worker: heat pipeline, NASA providers, accounts, trees, points, community, store, payments. |

Atmos X ships only as a web app and installable PWA; there is no native app.

## Run it locally

Needs Docker, Python 3.12+ with [uv](https://docs.astral.sh/uv/), and Node 22.

```bash
cp .env.example .env     # the core heat loop works with no third-party keys
make env                 # copies only the web variables into apps/web/.env.local
cd apps/web && npm ci && cd ../..
make dev                 # Postgres (5433) + migrations + reference data, then API (8000), worker and web (3000)
```

Open <http://localhost:3000> and choose "Try the Dhaka demo", or open `/app?demo=1`. The demo story is invented and never mixes with real data.

Other targets: `make test`, `make lint`, `make e2e` (Playwright, Chromium only), `make gen-client` (OpenAPI → typed web client), `make verify-sources` (one real request per data source), `make precompute` (Dhaka heat now). Create the first admin with `cd apps/api && uv run python -m app.scripts.make_admin you@example.org`.

## Deploy

`docker-compose.prod.yml` runs Postgres/PostGIS, the API, the worker and the web server; `deploy/` holds the nginx site. See [DEV-CHECKLIST.md](DEV-CHECKLIST.md) §5 before going live.
