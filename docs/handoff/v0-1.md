## Import cheat-sheet

```tsx
'use client';
import { Screen, ScreenHeader, Card, Txt, CzButton, I, B, useCz, go, SourceChips, ErrorState, Skeleton, requireAccount } from '@/components/cz';
import { useTranslations } from 'next-intl';
```

Every kit module is a client module, so screens that use it are client components (`'use client'`). Page files can stay
server components that render a client screen component. Dynamic `params` in Next 16 is a Promise:

```tsx
export default async function Page({ params }: PageProps<'/[locale]/app/zone/[id]'>) {
  const { id } = await params;
  return <ZoneScreen id={id} />;
}
```

## Porting from React Native: what changed

- **`style`** takes an RN-style object **or array** with falsy entries, like RN's StyleProp. RN-only keys are converted to
  RTL-safe CSS: `paddingHorizontal/Vertical`, `marginHorizontal/Vertical`, `paddingStart/End`, `start/end`, `borderTopStartRadius…`;
  numeric `lineHeight` → px; `transform: [{ scale }]`; `shadow*` → boxShadow; `elevation` is dropped. Use `rn(style)` for a
  raw DOM element. Every kit component also accepts `className` (Tailwind).
- **`<View>`** replaces RN View. It's a div with react-native-web defaults: flex column, `position: relative`, `flex-shrink: 0`,
  min size 0. **`<HScroll>`** replaces `<ScrollView horizontal>`. `absoluteFill` replaces `StyleSheet.absoluteFill`.
- **Pressables:** `onPress` receives the DOM click event. `Tap`, `Card`, `ListRow`, `CzButton`, `GhostButton`, `PillButton`,
  `IconBtn` and `SectionTitle` (`actionHref`) accept **`href`** and render a locale-aware `<Link>` (or `<a target=_blank>` for
  http/mailto/tel/geo). Prefer `href` over `onPress={() => go(...)}` for plain navigation (prefetch, middle-click).
  **Don't nest a Tap inside a pressable Card or ListRow** (that would put a button inside a button).
- **Fonts:** `font(w)` returns only the family. On the web, weight is separate, so use `style={{ ...fw(600) }}`
  (`fw` maps weights per script: bn 700 → 600, ur → 400/600). `<Txt w={600}>` already does this.
- **`ActivityIndicator`** → `<Spinner>` (an `ActivityIndicator` alias exists). **expo-haptics** → `haptic(ms)` (only after a
  user gesture). **StatusBar light** → `<LightStatusBar/>` (navy theme-color while mounted).
- **Palette:** `c.*` values are CSS variables (`var(--cz-ink)`), so they follow light/dark with no re-render. Use them in
  style props and SVG. For MapLibre, canvas or QR, use `raw` from `useCz()` (hex for the resolved theme) or `LIGHT` / `DARK`.
  `c.accent` = blue in light, lime in dark: use it wherever the mobile code wrote `c.dark ? B.lime : B.blue`.
  `c.dark` is false during SSR and hydration and becomes correct after mount.
- **Tailwind tokens** if you prefer classes: `bg-bg bg-card bg-soft text-ink text-ink2 border-line text-leaf bg-solid text-on-solid
  bg-lime-soft text-accent`, brand `bg-navy bg-lime text-lime-ink bg-blue text-red bg-orange…`, `rounded-cz-{sm,md,lg,xl,xxl}`,
  `shadow-cz-{card,button,fab,sheet}`, `font-body font-display`. Dark variant: `dark:`. Breakpoint for desktop: `lg:` (1024 px).
  Kit classes sit in `@layer components`, so utilities override them.

## useCz() (src/lib/prefs.tsx)

`const { c, raw, dark, f, lang, font, fw, display, latinDisplay, prefs, ready, setPref, setPrefs, setLang } = useCz();`

- `prefs` is the shared store shape from `src/lib/prefs-store.ts` (V0-3 hooks read the same store, so they stay in sync).
  Mobile → web key mapping: `prefs.farmer` → **`prefs.farmer_mode`**, `prefs.askOn` → **`prefs.ask_on`**, `prefs.radius` →
  **`prefs.radius_m`**, `prefs.dark` → **`dark`** (`prefs.theme` is light/dark/system). `prefs.trees` moved to `useTrees`.
- `ready` is false until IndexedDB has been read; until then `DEFAULT_PREFS` apply (onboarded: false). Don't redirect on `!ready`.
- `setPref('lang', l)` / `setLang(l)` stores the language **and switches the locale route**. `setPref('theme', t)` drives
  next-themes (persisted, no flash). The rendered locale always comes from the URL (`lang`). On first load, an unprefixed URL
  follows the stored language, and an explicit prefix (`/ur/...`) updates it.
- `f` = formatter (src/lib/format.ts, all 10 locales): `loc` (native digits for bn/ur/ar), `deg`, `temp`, `dC`, `tk`,
  `money(Money)`, `num`, `dec`, `pct`, `dist(m)` (metric/imperial per `prefs.area`), `area2(m²)`, `date`, `weekday`, `time`,
  `rel`, `pick` (legacy dictionaries; prefer i18n), `rtl`, `backPath`, `fwdPath`, `arrowPath`. `initials(name)` is exported.

## Routes (src/lib/routes.ts)

- `ROUTES` keeps the mobile screen IDs mapped to the §4.3 paths. `EXTRA_ROUTES`: `landing, tree, about, login, register, join, kit`.
- `go(id, params?, query?)`, `goPath(path)`, `goReplace(id, …)`, `goBack()` are **plain functions** (as on mobile) and keep
  the locale prefix. Path params fill `[id]`/`[code]`; any extra params become query strings:
  `go('S06', { id: zone.id })`, `go('S08', { zone: zone.id })` → `/app/goal/new?zone=…`, `go('tree', { id })`.
  A dynamic screen called without its param falls back to its parent (S06 → S05). `go('S29')` opens Ask Atmos.
- `href(id, params, query)` builds a locale-less path for `href` props or `<Link>` (from `@/i18n/navigation`).
- `goBack()` goes back when there is in-app history, otherwise to `/app`.
- `screenIdForPath(pathname, farmer)` maps a path to its ScreenId (Ask Atmos context).
- Farmer mode: the 2nd tab is labelled "Fields" and still points to `/app/map` (as on mobile, where the map tab renders MyFields).
  `/app` renders Home or FarmHome. F03 = `/app/farm/fields`.
- `/app` redirects to `/app/onboarding/welcome` while `prefs.onboarded` is false (in the app shell, not the page).
  `?demo=1` on any /app URL sets `presentation: true`.

**Placeholders:** every §4.3 route exists and shows its screen ID and owner. Porters replace the page bodies only:
V0-4 `app/{page,onboarding/*,map,zone/[id],zone/[id]/projection}`; V0-5 `goal/new, goal/[id]/feasibility, plan,
species/[id], nurseries, budget, log-action, contribution/[id]`; V0-6 `community, team/[id], team/new, org/[id], profile,
tree/[id], notifications, settings, about`, plus `src/app/[locale]/auth/{login,register}` and `src/app/[locale]/join/[code]`
(outside the app shell: no tab bar); V0-7 `air, air/devices, air/add, farm/alert/[id], farm/fields`; V0-9 `(marketing)/page.tsx`.
Tab roots (`/app`, map, plan, community, profile) pass **`<Screen tab>`**. The floating tab bar only shows on those
(+ `/app/farm/fields` in farmer mode), as on mobile. The desktop sidebar shows on every /app route except onboarding.

## i18n

- next-intl v4, 10 locales, `localePrefix: 'as-needed'` (English unprefixed). `<html lang dir>`: RTL for ur and ar.
- Messages: `src/i18n/messages/{locale}/{namespace}.json`, namespaces `common nav onboarding home map zone plan act community
  profile air farm ask auth landing server`. All exist as `{}` for every locale (except `server.json`, which V0-2 owns; missing
  files load as `{}`). All namespaces load for every request, nested under the namespace key: `useTranslations('home')`.
- **Every locale is deep-merged over English**, so a missing bn/ur/hi key shows the English string. A key missing in English
  too renders its last segment and only logs a warning in dev (no crash).
- V0-1 filled **`common`** (back, close, retry, loading, errors, empty, offline, install, account sheet, source chips,
  `risk.{ok,caution,xcaution,danger,xdanger}`, `aqi.{good…hazardous}`, heatScore…) and **`nav`** for en/bn/ur. Reuse
  `common.risk.*` and `common.aqi.*` rather than duplicating them.
- Server text: `const ts = useTServer(); ts(zone.causes[0])` (from `@/i18n/server-text`) → `t('server.<code>', params)`.
  Plain strings pass through; unknown codes are humanised. Nest codes in server.json: `{"cause": {"sealed_surface": "…"}}`.
- Locale switcher names: `LOCALE_NAMES` from `@/i18n/routing`.

## Location (src/lib/location.tsx)

`const { device, focus, placeName, permission, loading, error, custom, pinned, ready, refresh, setFocus, resetFocus, search } = useLocation();`

- The permission prompt is **never** shown automatically. S03 and "Use my location" call `await refresh()` (returns the
  LatLng or null; `error` is 'denied' / 'unavailable' / 'timeout'). If permission was already granted, the position is
  fetched automatically once onboarded.
- `focus` is the point being analysed (defaults to the demo point until a fix arrives). `setFocus(p, name?)` picks a city or
  spot; `resetFocus()` goes back to the device position. The focus is persisted in IndexedDB.
- `search(q)` → `Place[]` from `GET /api/v0/geo/search`, falling back to `STATIC_PLACES` (Dhaka neighbourhoods + major cities).
  `placeName` comes from `/api/v0/geo/reverse` (falls back to the nearest static place).
- Presentation mode (`prefs.presentation`) pins `focus` to `NEXT_PUBLIC_DEMO_LAT/LNG` ("Mohammadpur, Dhaka"); `pinned` is true.

## Guest gate: requireAccount()

- `requireAccount(featureText?)` opens the global "Create a free account" sheet (perks list, Create → `/auth/register?next=…`,
  Sign in → `/auth/login?next=…`, Not now). Example:
  `if (session.guest) return requireAccount(t('logAnAction'))`.
- It also opens **automatically** when any TanStack query or mutation throws `GuestRestrictedError` (QueryCache/MutationCache
  `onError` in src/lib/query.tsx). For passive reads that may throw it for guests, set `meta: { silentGuest: true }`.
  `RateLimitedError` shows a "Daily limit reached" toast. QueryClient defaults: staleTime 5 min, 1 retry (none on 4xx),
  no refetch on focus.
- `ErrorState error={e}` shows the account CTA for guest errors on its own.

## PWA

- `src/app/manifest.ts`: Atmos X, start_url `/app`, standalone, `#00182E`, icons 192/512 + maskable (generated with `sips`
  from the Expo icon).
- `public/sw.js` registers **only in production builds** (dev unregisters stale workers). It precaches the shell +
  `/offline.html`; navigations are network-first → cache → offline page; `/_next/static`, icons and fonts are cache-first;
  `GET /api/v0/{conditions,air,zones,farm/alerts,nurseries,species}` are stale-while-revalidate; POST requests and
  `/api/v0/ask` are network-only. **Bump `VERSION` in sw.js when caching rules change.**
- Install banner: on tab roots after onboarding (dismiss hides it for 14 days). It uses `beforeinstallprompt`, or the iOS
  Share → Add to Home Screen hint. The landing "Install" button uses `useInstall()`. The offline pill shows while `navigator.onLine` is false.

## Proxy (src/proxy.ts)

Sets `atmos_device` (UUID, 1 year, httpOnly, sameSite lax, path /, Secure over HTTPS) when it's missing. On the first request
it's also injected into the request's Cookie header, so **route handlers can read it straight away with
`cookies().get('atmos_device')`**. It runs next-intl only for pages, never for `/api`, `/_next`, `sw.js`, the manifest,
icons/brand or files with an extension. The matcher skips static assets entirely.

## Decisions / gotchas

- The `/dev/kit` page lives at `src/app/[locale]/dev/kit` (so `/ur/dev/kit` works), not at `src/app/dev`.
- Display face: Lemon/Milk for en/es/fr/pt/id. Other scripts use their Noto body face at 600 (as on mobile, extended to
  10 locales). The Urdu line height is 1.9 in `Txt`. Non-Latin Noto fonts don't preload; they load by unicode-range when used.
- `theme-color` follows light/dark (`#F2F4F7` / `#00182E`). `<LightStatusBar/>` forces navy on photo/map screens.
- Locale detection is on: a browser with `Accept-Language: bn` is sent to `/bn/...`, and that becomes the stored language.
- The kit gallery has inline English demo strings (dev-only). Placeholder and landing copy is in `common`.
