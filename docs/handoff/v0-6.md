## Helpers others can reuse

- `components/profile/codes.ts` → `useCodeText()` with `{text, action, level, badge, species, reason}`. It renders data-layer I18nText codes, looking in `server` first, then `profile.code`, then a humanised fallback. It also pre-formats notification params: action ids → titles, reason codes → sentences, native digits.
- `components/community/invite-card.tsx` → `InviteCard({team})` and `useQrDataUrl(text)` (`qrcode` is loaded on demand).
- `components/profile/settings.tsx` → `SwitchVisual({on})` (RTL-aware).

## Gaps / notes for other prompts

1. **V0-3 / Integrator: cross-device join of locally created teams.** This blocks "join from a second browser profile" for teams created in-app; seeded codes already work. `joinByCode` only finds seed teams plus teams in the *joiner's own* namespace, so a team created in browser A can't be found in browser B (or even by another account on the same browser). The UI already sends a preview payload (`?t=` from `components/community/invite-link.ts`, type `InvitePayload {i,n,m,c,o?,e?,by?}`).
   - Proposed fix: `joinByCode(ctx, code, invite?)`. When the code isn't found and `invite` is given, insert a `LocalTeam {id: invite.i, code, name: invite.n, max_members: invite.m, org_id: null, owner_id: 'remote', …}` and a `member` membership.
   - Then widen `useJoinByCode` to accept `string | {code, invite}`.
   - Then in `components/community/join.tsx`, pass `{ code: team.code, invite: preview }` from `NotFound` (today it shows "created on another device").
2. **V0-1: `?demo=1` is lost on locale-prefixed URLs** (`/bn/app/...?demo=1`). Two `setPrefs` calls race: the `presentation` one from the app shell, and the `lang` sync in `prefs.tsx`. Both `await getPrefs()` before `current` is set, so the last write wins.
   - Fix: memoise the `getPrefs()` promise in `src/lib/prefs-store.ts`.
   - Workaround: open `/app?demo=1` (unprefixed) first, or use the Settings switch.
3. **V0-2 / V0-3:** the `server` namespace has no `action.<type>`, `unit.*`, `level.*`, `badge.*` or `notif.*` texts. V0-6 keeps English copy for them under `profile.code.*`, and `useCodeText` picks up `server` keys automatically if they're added later.
4. **No hook for discoverable teams.** "Discover teams" uses the area team leaderboard rows + `useTeam(id)` and only shows teams that exist (seed or device) and are public. A `usePublicTeams()` would be cleaner.
5. **V0-5:** the team page's empty-activity CTA links to `/app/log-action?team=<id>`. Pre-selecting the team from that param would be nice.
6. **Seed team goals:** outside Presentation mode, seed teams have `goal_id: null`, so S17 shows team cooling + "Set a goal" instead of the 38 % ring. In Presentation mode the ring shows.
7. **Left out on purpose:**
   - Mobile's privacy and notification-type toggles in Settings: nothing backs them in v0, so they would be dead controls.
   - The photo-basemap pin picker in "Add tree": trees are saved at the current focus location instead.
   - `team_invite` notifications: the data layer never creates them.
8. Untranslated bn/ur strings fall back to English (V0-8). The Urdu tree page shows mixed "۴۷ days" until then.
