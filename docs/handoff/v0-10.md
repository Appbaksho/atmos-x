# V0-10 handoff: presentation hardening

Status: **done**. `npm run typecheck`, `npm run lint` (0 problems), `npm test` (17 files / 107 tests) and `npm run i18n:check` all pass.
I checked everything against a **production build** (`next build` + `next start -p 3100`) in an isolated copy of `apps/web`, using headless Edge over CDP at 390×844 and 1280×800, in en / bn / ur, light and dark. The shared dev server on :3000 was left running.

## What I fixed

### Integration issues

1. **MapLibre worker is self-hosted (no CDN).**
   - `scripts/vendor-maplibre.mjs` copies `maplibre-gl-{worker,shared}.mjs` from `node_modules` into `public/maplibre/<version>/`. It runs as `predev` / `prebuild` and removes old version folders.
   - All three maps (`map/map-view.tsx`, `plan/geo-map.tsx`, `farm/field-map.tsx`) call one helper, `src/lib/maplibre.ts` → `configureMaplibre(ml)`. That points `setWorkerUrl` at `/maplibre/<getVersion()>/maplibre-gl-worker.mjs`. `NEXT_PUBLIC_MAPLIBRE_WORKER_URL` still overrides it.
   - Verified in the prod build: the page loads only `localhost/maplibre/6.12.0/*`, with no jsdelivr or unpkg requests.
   - The folder is served `immutable` (`next.config.ts`) and cached cache-first by the SW. It is excluded from ESLint.
   - **Commit `public/maplibre/`**, or rely on the pre-hooks.
2. **RTL number order is fixed in the shared formatter.** In RTL locales (ur, ar), `src/lib/format.ts` wraps `deg`, `temp`, `dC`, `tk`, `money` and `area2` in FSI…PDI isolates. LTR locales are unchanged.
   - New helpers: `f.dAbs` (unsigned delta, used by Home's "above normal"), `f.iso`, `bidiIsolate` and `stripBidi`.
   - `components/plan/bidi.ts` is **deleted**. Plan and Act now use the shared formatter.
   - `coolingText` (community) handles the isolate.
3. **Link params are honoured.**
   - `/app/goal/new?zone=&focus=sealed|green|roofs|density` shows a "Starting with · <driver> / <fix>" card in the wizard (`GoalFocus` type).
   - `/app/log-action?goal=&type=` already worked.
   - `?team=<id>` now preselects that team as the credit, once it is one of my teams.
4. **Server fixes.**
   - **(a) `anomaly_c`:** the server was already right (today's forecast max − normal max for the date). The Home copy now says so: en "Today's high {d} above/below normal" / "Today's high is normal for the date". bn and ur already had matching wording.
   - **(b) BMD source chip:** it is added only when today's `bmd_level` is non-null (`weather/conditions.ts`).
   - **(c) Not-found errors:** unknown zones return `404 {code:"zone.not_found"}` from the detail, projection and planting-spots routes. Species return `species.not_found`. A new catch-all, `api/v0/[...rest]`, returns JSON `404 not_found` for unknown `/api/v0` paths. Every error path I probed returns JSON.
   - **(c, UI side):** Zone and Projection show "This zone isn't on the map any more → Open the map" (`components/zone/zone-not-found.tsx`) instead of a retry loop.
   - **(d) Raw numbers in server text:** `useTServer` formats numeric I18nText params (grouping, ≤ 2 decimals, native digits; years stay ungrouped) through `formatTextParams` in `lib/format.ts`. So "2,920 m²" and "২,৯২০" render correctly.
   - **(d, server side):** `src/server/i18n.ts` now loads all 10 `server.json` files, and Urdu server numbers use ۰–۹.
5. **`/bn/app?demo=1` in a fresh profile works.** The prefs race was fixed, but a second race remained: the onboarding gate redirected to S01 before the write landed. `?demo=1` now sets `{presentation, onboarded}`, and the gate ignores the redirect while the param is present. Verified in a fresh Edge profile: Nadia's story loads on `/bn/app?demo=1`.

### Found during the demo walk

- **Projection sliders seeded cool roof at 1/10.** `PlanAction.qty` counts 10 m² units, so the sliders showed 292 m² against the plan's 2,920 m². This is fixed.
- **Species names were wrong in bn and ur.** The API's `name` is already localised and `local_name` is the *other* name, so ur showed Bangla names and bn showed English ones. Log-action, the plan species card, the catalogue, species detail and the tree name helper now use `name`.
- **Plan didn't render offline.** The plan comes from a POST, which the SW can't cache. `usePlan` now keeps the last good plan per goal in IndexedDB and serves it, marked `live:false`, when the network or server fails.
- **Urdu hero overlap.** The Nastaliq digits overlapped the "above normal" pill, so the hero now has extra bottom space in ur.
- **Install banner on the Map.** It is no longer shown there, because it covered the legend, the layer switch and the desktop zone panel.
- **Prefetch along the script.**
  - Home warms the rank-1 zone detail (AI "why") and the MapLibre chunk on idle.
  - Map warms the hottest zone.
  - Zone warms its planting spots for the goal wizard (`usePrefetchZone` in `hooks/heat.ts`).
  - Home's scan is the same query the Map uses, so Map → zones is instant.
- **Coordinator's i18n list:**
  - Map subtitle is one message, `map.withinR` "Within {r}".
  - The WHO tick label is centred on a zero-width anchor, so it no longer clips in ar/ur.
  - `air.sensorsSub` wraps to 2 lines.
  - Every `{n, plural, … # …}` message (`air.devSub`, `act.unit.{tree,plants_10,structure,session,event}`, `act.log.treesAdded`, `farm.home.more`, `farm.alert.leadDays`, `farm.fields.sub/subArea`) is now `{count, plural, … {n} …}`. Callers pass `count` (number) and `n` (native digits), in all 10 locales, so ur shows "۱ سینسر".

### Offline safety net and PWA

- **Upstream env overrides** live in `src/server/env.ts` (`env.upstream`):
  - `OPEN_METEO_BASE_URL` changes the host of all four Open-Meteo APIs.
  - Each API also has its own override: `OPEN_METEO_{FORECAST,ARCHIVE,AIR,GEOCODING}_URL`.
  - The others are `NOMINATIM_URL` and `NASA_POWER_URL`.
  - They are documented in `.env.example`.
- **Snapshot fallback verified.** I ran a second prod server with these overrides, `OVERPASS_URLS` and `OPENAI_BASE_URL` all pointed at `http://127.0.0.1:9`, plus an empty `ATMOS_CACHE_DIR`. Results:
  - Every demo endpoint answers in < 1 s with `meta.live=false` from `snapshots/dhaka`: conditions, zones 500, zone with the AI why in bn, projection, spots, air, farm, nurseries, species, reverse geocode.
  - Plan falls back to deterministic numbers.
  - Ask streams the canned answer with a notice in 2.5 s.
  - Every demo screen renders in en at 390 px.
- **Versioned SW.** `next.config.ts` stamps each build into `NEXT_PUBLIC_BUILD_ID` (override with `ATMOS_BUILD_ID`). The SW registers as `/sw.js?v=<stamp>`, and cache names are `atmos-v0-2-<stamp>-*`.
  - On `activate`, every cache from older builds is deleted. I verified this: after a rebuild only the new stamp's caches remained.
  - With the browser offline after warming, `/app`, `/app/map`, `/app/plan`, the zone page and settings all rendered from the SW plus device data.
- **Security.** The OpenAI key is not in `.next/static` or `.next/server`.
- **Performance and layout.** Home CLS is 0 at 390 px and 0.05 at 1280 px (an early sidebar shift, under the 0.1 "good" line); LCP is about 150 ms locally. MapLibre loads only via `next/dynamic` / dynamic `import()`.
  - Lighthouse was not run: it isn't installed, and I followed the no-install rule.

## Presentation checklist

1. **Morning of:**
   - In `apps/web`, run `npm run snapshot:dhaka` (re-records the Dhaka snapshots in daylight, so Heat Scores spread better than the night-time ones).
   - Then run `npm run build && npm start` (or deploy). The build stamp changes, so phones pick up the new SW on the next load.
   - Open `/app/map?demo=1` once on each device to warm the scan, zone AI text and tiles.
2. **Reset:**
   - Settings → Presentation mode → **Reset demo** reloads Nadia's story.
   - In a fresh browser just open **`/bn/app?demo=1`**. Onboarding is skipped and Mohammadpur is pinned.
   - To show onboarding, open `/bn/app/onboarding/welcome` and tap "Try the Dhaka demo".
3. **Devices:**
   - Android Chrome with the installed PWA (HTTPS tunnel; the camera needs HTTPS).
   - A laptop Chrome window at ≥ 1024 px for the two-pane map.
4. **Language order:** start in বাংলা (`/bn/app?demo=1`) for steps 2–13. Then switch Settings → Language → اردو for RTL, then toggle dark mode (step 14). English is the fallback if a bn string looks off.
5. **Script path:**
   - Home → Map (hottest = rank 1, "Asad Gate block" goal is bound to it) → Zone → See projection (move the trees slider).
   - Set a cooling goal (or "Add to goal" on a driver) → feasibility → Plan (৳, species, spots map) → Log action (camera → AI verify → See contribution → share).
   - Community → Hall Rooftop Crew → Invite QR → Profile → Beguni (due) → check photo → Air → Settings: Farmer mode → Home shows Boro/flowering alerts → Ask ("আমার এলাকা এত গরম কেন?") → tap the action.
6. **Fallback plan:**
   - **Wi-Fi drops:** the SW and snapshots carry every screen (shows "cached" chips). Ask switches to the canned answer, and photo verify stores the action as *pending* ("A teammate can confirm it"), so explain that live.
   - **Overpass is slow:** snapshots answer within the 25 s deadline. Pre-warming (step 1) avoids the wait.
   - **A zone link is stale:** the "zone isn't on the map any more → Open the map" screen appears; re-pick the zone from the map.
   - **Total failure:** use the second device, or the laptop with the dev server.
